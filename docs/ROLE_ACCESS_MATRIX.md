# Matriks Hak Akses Pengguna (RBAC)

Sistem Rak Digital membagi hak akses ke dalam dua peran utama untuk menjaga integritas operasional perpustakaan:

| Fitur / Modul | Admin | Pustakawan |
|---|---|---|
| Ringkasan Dashboard | Ya | Ya |
| Lihat & Cari Koleksi Buku (Catalog) | Ya | Ya |
| Tambah / Ubah / Hapus Buku, Penulis, Kategori | Ya | Tidak |
| Transaksi Peminjaman & Pengembalian (Circulation) | Ya | Ya |
| Pengelolaan & Pelunasan Denda (Fines) | Ya | Ya |
| Kelola Data Anggota (Membership) | Ya | Tidak |
| Kelola Jenis Keanggotaan (Membership Types) | Ya | Tidak |
